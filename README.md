# Rangoli

Rangoli is an AI-native, agent-first design and prototyping tool for building product interfaces with humans and coding agents in the same workflow.

Instead of hand-authoring HTML and CSS, teams describe UI in a compact text language called RDL, then iterate visually, review changes, and export polished interfaces with tokens, layouts, motion, and prototypes that stay on-system and themeable.
